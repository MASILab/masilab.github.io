--- layout: default --- {% comment %} Gallery layout for just-the-docs. Inherits all site chrome (head, sidebar, header, breadcrumbs, footer, search) from `default.html`, exactly the way home.html / page.html / post.html do — it just replaces {{ content }} with a card grid, then still renders {{ content }} underneath in case the page also has prose (an intro paragraph, usage notes, etc.) below the front matter. Usage — either supply items directly in page front matter: --- layout: gallery title: Tools nav_order: 2 gallery_items: - title: toolname summary: One line on what it does. image: /assets/images/tools/toolname.png url: /docs/toolname/ repo: https://github.com/yourlab/toolname tags: [dMRI, registration] --- ...or point at a data file (site/_data/tools.yml) with the same per-item shape, for a lab-wide roster you maintain in one place and reuse across pages: --- layout: gallery title: Tools gallery_data: tools --- Only `name` and `url` are required per item; everything else is optional and simply omitted from the card if absent. THIRD MODE — auto-collect child pages: if you set neither `gallery_items` nor `gallery_data`, the layout falls back to finding every page whose front matter `parent:` matches this page's `title:` (exactly the same relationship just-the-docs itself uses to build the sidebar tree — see components/children_nav.html), and builds cards from each child's own front matter: --- layout: gallery title: Tools has_children: true nav_order: 2 --- # tools/fixelflow.md --- title: fixelflow parent: Tools summary: Fixel-based analysis pipeline with automated QC reporting. image: /assets/images/tools/fixelflow.png repo: https://github.com/yourlab/fixelflow tags: [dMRI, fixel, Snakemake] --- This only collects direct children, matching how has_children/parent nesting works — grandchildren (three-level nesting) are not pulled in automatically. A child's `summary` falls back to `summary` (the field just-the-docs' own children-nav blurb uses), so pages that already have a `summary:` for the built-in nav need no extra field. Pages with `nav_exclude: true` are skipped. Ordering follows `nav_order`, same as the sidebar. {% endcomment %} {% if page.title %}
